QUESTION 1:

Title: Sum of Multiples of 3 and 5
Topic: Math & Logic
Difficulty: Easy
Marks: 10

Problem Statement:
Given a positive integer `n`, find and return the sum of all positive integers from 1 to `n` (inclusive) that are divisible by either 3 or 5.

Input Format:
A single integer `n`.

Output Format:
A single integer representing the calculated sum.

Constraints:
1 <= n <= 10000

Sample Input:
10

Sample Output:
33

Explanation:
Multiples of 3 or 5 up to 10 are: 3, 5, 6, 9, 10.
Sum = 3 + 5 + 6 + 9 + 10 = 33.

Title: Valid Parentheses Checker
Topic: Stack & Strings
Difficulty: Medium
Marks: 15

Problem Statement:
Given a string `s` containing only the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid and balanced.
A string is valid if:
1. Open brackets are closed by the same type of brackets.
2. Open brackets are closed in the correct nested order.

Input Format:
A single string `s`.

Output Format:
Print "YES" if valid, otherwise print "NO".

Constraints:
1 <= length of s <= 100000

Sample Input:
{[()]}

Sample Output:
YES

Explanation:
All open brackets are closed correctly by their matching bracket types in proper order.

QUESTION 3:
--------------------------------------------------------------------------------
Title: Find Maximum Subarray Sum
Topic: Dynamic Programming
Difficulty: Medium
Marks: 15

Problem Statement:
Given an array of integers, find the contiguous subarray (containing at least one number) which has the largest sum and return its sum.

Input Format:
First line: n (array size)
Second line: n space-separated integers

Output Format:
A single integer representing the maximum subarray sum.

Constraints:
1 <= n <= 100000
-10000 <= arr[i] <= 10000

Sample Input:
9
-2 1 -3 4 -1 2 1 -5 4

Sample Output:
6

Explanation:
The contiguous subarray [4, -1, 2, 1] has the largest sum = 6.

[Test Case 1]

Expected Output:
6
Is Hidden: False

[Test Case 2]
Input:
5

Expected Output:

Is Hidden: True
